# Signify
perl module wrapper for OpenBSD signify, to simplify creating and verifying detached
file signatures and signatures in gzipped tar files (e.g., signed packages).
Also works on Linux with signify-openbsd package and on macOS with signify-osx (Homebrew).

Also available at https://www.discord.org/lippard/software

p5-Signify-1.1f.tgz is a Legion of Dynamic Discord signify-signed OpenBSD package. Signify public key is https://www.discord.org/lippard/software/discord.org-2026-pkg.pub

Current version is Signify-1.1f of 11 January 2026.
