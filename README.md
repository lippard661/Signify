# Signify
perl module wrapper for OpenBSD signify, to simplify creating and verifying detached
file signatures and signatures in gzipped tar files (e.g., signed packages).
Also works on Linux with signify-openbsd package.

Also available at https://www.discord.org/lippard/software

p5-Signify-1.1c.tgz is a Legion of Dynamic Discord signify-signed OpenBSD package. Signify public key is https://www.discord.org/lippard/software/discord.org-2025-pkg.pub

Current version is Signify-1.1c of 10 November 2025.
